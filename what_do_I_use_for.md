## What Do I Use For.....?

If you haven't noticed: I'm a **huge** fan of integrating new technology into CS Education 😊 There are many tools that we'll use to learn more effectively this term.

This page will help you keep track of these tools, as well as what each of them is used for! If you ever have a question, please don't hesitate to reach out to the instructor.

### Class Website: Overview + Schedule + Lecture Materials

If you aren't sure where to find something you need, the class webpage (yes, the one that you are looking at right now) is a great place to start!

Probably the _most_ useful thing about this website is the fact that the homepage contains our calendar for the entire term: which topics we'll learn, when we'll learn them, and when everything is due (wrapped up in one place). That calendar also links to the lecture materials for each week.

### GitHub Classroom: Downloading and Submitting Coding Assignments

We'll use GitHub classroom to submit the coding assignments (that means labs and homeworks) in this class. You'll have a "repo" of code created for you, where you'll also upload your final submission.

The nice thing about GitHub classroom is that it auto-grades your code once you upload it: so you'll know right away whether you got full marks on the lab or not.

### Canvas: Q&A Forum + Grades

We'll mainly use Canvas to host the general Q&A discussion board this term. This discussion is pinned on the CSCI 110 Canvas, and also linked from the top bar of this webpage. I **really** prefer you asking your questions here instead of email, assuming they aren't too personal. That way other students can also learn from your question (and probably have the same one!)

We'll also use Canvas to store your grades this semester (grades for coding assignments should exactly match what the auto-grader gave you on GitHub Classroom).

### Discord: Queuing for Help + Socializing

We will also use Discord this semester, which I'm sure many of you are familiar with! We'll _specifically_ be using it for

1. **Most Importantly:** Queuing for live help during class time and office hours (see `#⁠live-help`)
2. Community building and socializing (see `#⁠group-finding` and `#⁠random`)

### Email: Private Questions

If you have a question that's very private or too personal for the Canvas Q&A, feel free to send me an email!
