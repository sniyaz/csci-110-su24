## Accounts in CSCI 145

Heads up: there are two accounts I expect you to create this semester (if you don't already have them).

### GitHub Account

The first account is for GitHub, since we will use GitHub classroom to submit assignments in this class. You can create a GitHub account [here](https://github.com/signup) if you need one. You can use any email you'd like to sign up, I just need your handle once you have an account. For example, my GitHub handle is [sniyaz](https://github.com/sniyaz).

Don't worry about actually setting up GitHub Classroom or anything like that: just create the account/handle you'll use this semester. We'll walk through GitHub Classroom setup in Lab 0.

### Discord Account

We will use Discord as the class forum this quarter, where you can ask questions about assignments, lecture, or anything else (I hate Canvas discussion boards with a fiery passion). That means you need to sign up for Discord and tell me what your handle is here as well. You can see [this page](https://support.discord.com/hc/en-us/articles/360033931551-Getting-Started) for directions.

Once you've created a Discord account, use that account/handle to join the class Discord server! You can find the link in the upper right of this page (it's the big button that says..._Discord_ 😉).

**Note:** By default, people who join the class Discord are restricted and can't do anything (this is for safety reasons). Don't be confused by that: I will manually add the discord handle you give on the form below to the "Student" role (which will allow you to actually post and view).

### Account Linking

1. Actually give you credit for the labs and homeworks you submit on GitHub Classroom.
2. Un-restrict you on Discord now that I know you aren't some random person.
