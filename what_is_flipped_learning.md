## What Is "Flipped" Learning?

Our class this semester will be taught online at set times (you can see the [weekly schedule](https://sniyaz.github.io/csci-110-su24/schedule/) for exactly when our classes are held). Based on my own experience teaching online classes during COVID, I've decided to implement a ["flipped" learning](https://en.wikipedia.org/wiki/Flipped_classroom) approach this semester.

At a high level, this means that I will **pre-record** the lectures for you to view on your own time. This is nice because (in my experience) trying to lecture "live" over Zoom just doesn't work well. There are often connection issues, and a video (unlike a live lecture) can be paused and rewound if there's something you don't quite understand!

You will be **required** to watch these pre-recordings before attending our actual class sessions on Zoom. The nice thing about this is that you can watch them at any time that works for you. During the "live" class itself, you will work on a lab that builds on the lecture, and also have the chance to ask me questions about the lecture that you're still confused on! So there will still be plenty of chances for us to have "face-to-face" interaction.

## What Exactly Will Happen?

Breaking things down:

1. **Before Each Live Class:** I expect you to review the lecture pre-recording (and/or book chapter of the same number) that the lab that day requires. This information can be found next to each live class on our [course calendar](https://sniyaz.github.io/csci-110-su24/).

2. **During The First Hour (ish) of Each Live Class:** I will go over announcements to the entire class on the Zoom call. I will also use this time to see if there are any common questions shared by many people in the class, and address them to the whole group as well. 

3. **For The Rest of The Live Class:** I will give the GitHub Classroom code for the day's lab on the Zoom call. I will then open breakouts, which you are welcome to join with your partner (if you have one) to work on the lab! If you get stuck while you work on the lab (or if you have conceptual questions from the lecture/chapter), please "line up" for help by using the `#live-help` channel on Discord. You can read more about this process [here](https://sniyaz.github.io/csci-110-su24/schedule/).
